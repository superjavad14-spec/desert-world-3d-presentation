# بیابان‌های جهان

یک ارائهٔ سه‌بعدی و تعاملی برای درس مطالعات اجتماعی با موضوع بیابان‌های جهان.

## ویژگی‌ها
- محیط voxel و سه‌بعدی با Three.js
- حالت ارائه و حالت اکتشاف
- کنترل کامپیوتر و موبایل به‌صورت مجزا
- بخش‌های آموزشی کوتاه، دقیق و مناسب کلاس
- رابط فارسی و واکنش‌گرا
- سازگاری با نمایشگرهای مختلف

## اجرا

1. فایل‌ها را در یک پوشهٔ پروژه قرار دهید.
2. یک سرور محلی اجرا کنید، به‌عنوان مثال:

```bash
python -m http.server 8000
```

3. در مرورگر، آدرس زیر را باز کنید:

```text
http://localhost:8000
```

## ساختار پروژه
- `index.html`: ساختار صفحه و رابط کاربری
- `style.css`: طراحی و واکنش‌گرا بودن
- `app.js`: منطق سه‌بعدی، ارائه و کنترل‌ها

## منابع
